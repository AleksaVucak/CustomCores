How the builder works

Open the Custom PC Builder from the main navigation. You move through component categories one step at a time. Selections are stored in your browser session, so you can go back and change earlier steps without logging in.

  • Required steps must have a selection before you can finish.
  • Optional steps (Service) can be skipped.
  • The right-hand summary shows your running total, compatibility status, and a live performance preview.
  • On the last step, choose Review build to open the full summary.

Start building

Step 1 — CPU

Choose the processor. Match the socket (for example AM5 or LGA1700) to the motherboard you plan to use. Higher gaming or productivity scores usually mean stronger performance in those workloads.

Go to CPU step

Step 2 — Motherboard

The motherboard must use the same socket as your CPU and the same RAM type (DDR4 or DDR5) as your memory. Form factor (ATX, mATX, ITX) must fit inside your case. Some compact boards only support NVMe storage.

Go to Motherboard step

Step 3 — GPU

Graphics cards drive most gaming performance. Check the listed card length — your case must have enough GPU clearance. Powerful GPUs also raise the power draw, so plan a larger PSU.

Go to GPU step

Step 4 — RAM

Memory must match the motherboard’s RAM type (DDR4 vs DDR5). More capacity helps multitasking and creative work; speed and size both influence the productivity score.

Go to RAM step

Step 5 — Storage

Pick NVMe or SATA storage. Confirm the motherboard’s supported storage list includes your drive’s interface. Some ITX boards are NVMe-only.

Go to Storage step

Step 6 — PSU

The power supply must cover the estimated draw of all other parts, with about 20% headroom recommended. Below total draw is incompatible; enough wattage but less than 20% headroom triggers a warning.

Go to PSU step

Step 7 — Case

The case must fit your motherboard form factor, leave room for the GPU length, and support your cooler type (air and/or liquid). Larger ATX cases are the most flexible.

Go to Case step

Step 8 — Cooling

Air coolers must fit under the case’s maximum cooler height. Liquid (AIO) coolers need a case that supports liquid cooling. Compact cases may only allow low-profile air coolers.

Go to Cooling step

Step 9 — Operating system

Choose an OS option (or none if you will install your own). This step is required in the builder flow so your quote includes licensing if you need it.

Go to OS step

Step 10 — Assembly service (optional)

Optionally add assembly or setup services. You can Skip this step if you will build the PC yourself.

Go to Service step

Live pricing & trusted totals

As you change selections, the summary updates the this-step subtotal and running total immediately in your browser. CustomCore also rechecks prices on the server using database values, so a tampered browser price cannot change the trusted total.

The build summary page always shows the database-backed total for your selected parts.

Compatibility checking

Seven rules run against your selections. Status can be Compatible, Warning, or Incompatible.

  1. CPU and motherboard socket must match
  2. RAM type must match the motherboard
  3. Motherboard form factor must fit the case
  4. PSU wattage must cover estimated draw (with headroom guidance)
  5. Case GPU clearance must fit the graphics card
  6. Cooler must fit the case (height / liquid support)
  7. Motherboard must support the storage interface

Incompatible builds cannot be saved until you fix the failing parts. Warnings (for example low PSU headroom) still allow saving.

Performance chart

The performance visualization estimates gaming and productivity scores (1–100) from weighted CPU, GPU, RAM, and storage data. It also shows upgrade headroom compared with the best active catalogue parts.

If the chart graphic does not load, the same numbers appear as a text summary underneath.

Build summary

After the last step (or via Review build), builder-results.php lists every part with trusted prices, compatibility details, power estimates, and the performance chart. Use Edit beside any category to jump back to that step.

Saving builds

Guests can review builds freely. To save, log in (or register), complete all required parts, and resolve incompatible errors. On the summary page, enter a build name (and optional notes), then choose Save build to my account.

Prices and compatibility status are stored as a snapshot at save time.

Managing saved builds

Open Saved builds from your account menu to see every build you own. On a single build page you can:

  • Rename the build or update notes
  • Edit in builder — reloads the parts into the session builder
  • Delete the build permanently

You can only view or change your own builds. Another customer’s builds are never shown.

Tips & common mistakes

  • Pick CPU and motherboard sockets together — AM5 CPUs need AM5 boards.
  • Do not mix DDR4 RAM with a DDR5 motherboard (or the reverse).
  • Long high-end GPUs often fail in tiny ITX cases — check clearance.
  • Undersized PSUs are the most common late-step failure; follow the wattage estimate.
  • Use Start over if you want a clean session build.
  • After editing a saved build in the builder, save again from the summary to store the new configuration.
